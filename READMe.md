
# GestorPro

Sistema web de gestión de proyectos y tareas desarrollado
como proyecto de portafolio profesional.

## Objetivo

Facilitar la organización de proyectos, actividades,
prioridades y seguimiento del trabajo.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git y GitHub

## Funcionalidades previstas

- Dashboard con indicadores.
- Gestión CRUD de proyectos.
- Gestión de tareas y prioridades.
- Autenticación y roles de usuario.
- Reportes de productividad.

## Estado actual

Versión 0.1.0: estructura inicial e interfaz de demostración.

Los datos del dashboard son estáticos y no representan
información almacenada en una base de datos.

## Próximas etapas

1. Diseñar la base de datos.
2. Configurar PHP y PDO.
3. Implementar el CRUD de proyectos.
4. Incorporar tareas y autenticación.
5. Agregar pruebas y publicar la aplicación.
